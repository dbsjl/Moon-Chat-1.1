# Moon Chat 1.1.0 — обновление

## Отключить подтверждение почты при регистрации
Это нельзя отключить из HTML/JavaScript: настройка находится в Supabase.
1. Открой Supabase Dashboard и выбери проект Moon Chat.
2. Перейди в Authentication → Sign In / Providers → Email (названия пунктов могут немного отличаться).
3. Выключи **Confirm email**.
4. Сохрани изменения.

После этого новые пользователи смогут входить сразу после регистрации. Это уменьшает проверку владения почтой, поэтому включай только если это осознанный выбор.

## Что обновлено в проекте
- Учёт safe-area для строки состояния и нижней панели Android.
- Локальный кэш списка чатов и последних 500 сообщений каждого открытого чата для мгновенного первоначального отображения; данные затем обновляются из Supabase.
- Иконка Moon Chat.
- Разрешение Android на уведомления и локальные уведомления о новых входящих сообщениях, пока WebView подключён к Realtime.

## Важное ограничение уведомлений
Эта версия может показывать уведомления, когда приложение активно и Supabase Realtime получает событие. Для надёжных push-уведомлений, когда приложение закрыто или Android остановил его, нужно подключить Firebase Cloud Messaging (FCM), настроить Firebase-проект и серверную отправку уведомлений из Supabase. Без конфигурации Firebase нельзя честно обещать фоновые push-уведомления.

## Пересборка
Загрузи содержимое проекта в GitHub с сохранением структуры папок, затем запусти Actions → Build Moon Chat APK. Установи новый APK поверх старого, если Android разрешит обновление того же пакета.
