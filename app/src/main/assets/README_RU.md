# Moon Chat — запуск

Готовая стартовая веб-версия мессенджера с космическим тёмным интерфейсом, регистрацией, уникальным Moon ID и личными чатами в реальном времени.

## Что входит
- Адаптивный интерфейс для телефона и компьютера.
- Регистрация и вход по электронной почте и паролю; при включённом подтверждении почты нужно нажать ссылку из письма.
- Уникальный ID формата `MC-XXXXXXXX`.
- Поиск собеседника по Moon ID.
- Личные сообщения и обновление чатов через Supabase Realtime.
- Отправка фото до 8 МБ в личном чате через приватное хранилище Supabase Storage.
- Настройки и выход из аккаунта доступны из нижней части левой панели (на телефоне — кнопка ⚙ в списке чатов).
- Row Level Security (RLS): читать переписку могут только участники соответствующего чата.

## Важно о регистрации и шифровании
Supabase Auth использует email/пароль или другие поддерживаемые способы входа. Имя — это отображаемое имя профиля, а не секрет для авторизации. Не используй один только ник вместо пароля: это позволит другим выдавать себя за тебя.

Передача данных идёт через HTTPS, пароль обрабатывает Supabase Auth, а доступ к таблицам ограничивается RLS. Эта версия **не реализует сквозное шифрование (E2EE)**: сообщения хранятся в базе как текст. Не называй её E2EE-мессенджером и не отправляй через неё секретную информацию. Для E2EE нужно отдельно добавить обмен ключами и клиентское шифрование, включая безопасное восстановление/перенос ключей.

## Настройка Supabase
1. Открой https://supabase.com/ и создай проект. Для небольшой группы можно начать с бесплатного тарифа, соблюдая его текущие лимиты.
2. В панели проекта открой **SQL Editor → New query**.
3. Скопируй весь файл `supabase.sql`, вставь его в редактор и нажми **Run**.
4. Открой **Project Settings → API** (или раздел Connect) и скопируй Project URL и publishable/anon key. **Никогда не вставляй `service_role` / secret key в браузер.**
5. Открой `config.js` и замени:
   - `ВСТАВЬ_PROJECT_URL` на Project URL;
   - `ВСТАВЬ_PUBLISHABLE_OR_ANON_KEY` на publishable/anon key.
6. В **Authentication → URL Configuration** укажи URL, на котором будет размещён сайт. Для локального теста можно использовать `http://localhost:8080`.
7. В **Authentication → Providers → Email** проверь настройки подтверждения email. Если подтверждение включено, пользователь должен подтвердить адрес перед входом.
8. Выполни дополнительный SQL-файл `supabase_photos_realtime.sql` в **SQL Editor → New query**. Он добавит поддержку фото, создаст приватное хранилище и включит Realtime для `messages`. Если Realtime не включился автоматически, открой **Database → Publications** и включи таблицу `messages` в `supabase_realtime`.
9. Запусти сайт локально из папки проекта:
   - если установлен Python, выполни `python -m http.server 8080`;
   - открой `http://localhost:8080`.
   Не открывай `index.html` напрямую через `file://`, потому что некоторые функции браузера могут работать некорректно.
10. Для доступа друзей размести папку как статический сайт на любом подходящем бесплатном хостинге и добавь его адрес в URL Configuration Supabase.

## Ограничения и проверка
- Это MVP личных чатов, а не готовый опубликованный магазинный Android/iOS app.
- Для отправки фото обязательно один раз выполни `supabase_photos_realtime.sql` в Supabase.
- До запуска проверь регистрацию двух тестовых пользователей, поиск по Moon ID, отправку текстовых сообщений и фото, а также недоступность чатов для посторонних.
- Бесплатный тариф не означает безлимит: ограничения Supabase и хостинга могут меняться, поэтому проверь актуальные лимиты перед приглашением группы из 50 человек.
- Интерфейс загружает шрифт Google Fonts и Supabase JS с CDN, поэтому для работы требуется интернет.

## Структура
- `index.html` — экран входа и приложение.
- `style.css` — оформление Moon Chat.
- `app.js` — логика авторизации, контактов и переписки.
- `config.js` — настройки проекта Supabase.
- `supabase.sql` — таблицы, политики безопасности и функция создания личного чата.


## Вход по ссылке из письма
Укажи email (при регистрации также имя) и нажми кнопку. На почту придёт письмо подтверждения: открой его и нажми на ссылку. После подтверждения браузер вернётся на сайт Moon Chat. Если письма нет, проверь папку «Спам» и правильность адреса. В Supabase → Authentication → URL Configuration укажи адрес опубликованного сайта в Site URL и Redirect URLs.

## Имя отправителя письма
В шаблонах Supabase можно изменить тему и текст письма на Moon Chat. Чтобы изменить отображаемый адрес отправителя и убрать стандартный адрес Supabase, обычно нужен собственный SMTP-провайдер; большинство провайдеров требуют подтверждённый домен. Пока домена нет, можно оставить штатную отправку Supabase и оформить тему/содержание письма под Moon Chat.


## Вход по почте и паролю

В текущей версии вход выполняется через email и пароль Supabase. Для новых аккаунтов Supabase может по-прежнему требовать подтверждение адреса по электронной почте — это зависит от настройки Email confirmations в Authentication. Если подтверждение включено, лимит отправки писем Supabase всё ещё может влиять на регистрацию; смена формы входа на пароль сама по себе не увеличивает лимит. Не отключай подтверждение почты без понимания последствий.
